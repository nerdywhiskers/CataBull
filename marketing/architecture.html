Entry points

Users start through the global catabull CLI, npm run dashboard, or the static install scripts. The local Fastify dashboard runs at localhost:3737 and becomes the main control surface.

Key files
bin/catabull.mjs, start.mjs, dashboard-web/server.mjs, marketing/install.sh, marketing/install.ps1
Watch out for
Keep install scripts, package bin entries, and dashboard startup paths aligned. A broken entrypoint makes the project feel broken even if the internals are fine.
Local-first

Everything routes through a workspace.

User data stays in the workspace: CV, profile, portals, reports, pipeline, applications, memory, and generated output.

No database

Plain files make it inspectable.

Markdown, YAML, TSV, and generated files are easy for users and agents to audit, diff, repair, and back up.

Agent-ready

Modes are the control plane.

Claude Code, Codex, OpenCode, and Gemini can all follow the same project modes and data contract.
